# Lift

iOS-дневник силовых тренировок: подход записывается за 1-2 действия, чаще всего прямо с экрана блокировки. Код пишет команда ИИ-агентов по ТЗ из этого репозитория.

## Как запустить

Нужны macOS с Xcode 16 или новее, `xcodegen` (`brew install xcodegen`) и Claude Code.

```bash
cd lift
claude
```

Дальше написать агенту **«начинай»**. Главная сессия прочитает `CLAUDE.md`, проверит окружение, выберет симулятор и запустит задачи по волнам. Сама остановится на трёх гейтах, где нужен человек.

| Команда агенту | Что будет |
| --- | --- |
| «начинай», «продолжай» | Работа до следующего гейта |
| «статус» | Короткая сводка из `docs/STATUS.md` |
| «G0 ок», «G1 ок», «G2 ок» | Гейт пройден, работа продолжается |

## Что где

| Файл | Зачем |
| --- | --- |
| `CLAUDE.md` | Инструкции главной сессии: как быть оркестратором |
| `AGENTS.md` | Правила для любого агента: стек, стиль, границы, команды |
| `.claude/agents/` | Сабагенты `task-executor` и `task-reviewer` |
| `docs/SPEC.md` | Объём MVP, архитектура, модель данных, контракты модулей, дизайн-токены |
| `docs/ORCHESTRATION.md` | Волны, зависимости, гейты |
| `docs/STATUS.md` | Текущее состояние задач и гейтов, ведёт оркестратор |
| `docs/tasks/T00-T14` | По файлу на задачу |
| `docs/design/` | HTML-макеты экранов |

## Перед выпуском

Bundle ID `ru.nikita.lift` и App Group `group.ru.nikita.lift` выбраны для старта. Поменять их проще всего на гейте G0, до первой сборки на устройство.
