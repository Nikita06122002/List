# T13: Fastlane и CI

- **Волна:** 3 (можно раньше, зависит только от T00)
- **Зависит от:** T00
- **Блокирует:** гейт G2
- **SPEC:** раздел 4 (таргеты)

## Цель

Сборка в TestFlight одной командой и проверка каждого PR без участия человека.

## Файлы

- `fastlane/Fastfile`, `fastlane/Appfile`, `Gemfile`
- `.github/workflows/ci.yml`
- `docs/release.md`

## Что сделать

1. Lane `test`: `xcodegen generate`, тесты пакета `Core` через `swift test`, тесты схемы `Lift` через `scan`.
2. Lane `beta`: `xcodegen generate`, номер билда из `latest_testflight_build_number + 1`, `build_app`, `upload_to_testflight` без ожидания обработки. Авторизация через App Store Connect API key из переменных окружения `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_CONTENT`. Подпись автоматическая (`-allowProvisioningUpdates`), без match.
3. GitHub Actions: на каждый PR и пуш в `main` запуск lane `test` на `macos-15` с последним стабильным Xcode. Кеш SPM.
4. `docs/release.md`: какие секреты завести, как выпустить билд руками, что делать при ошибке подписи.

## Критерии приёмки

- [ ] `bundle exec fastlane test` проходит локально.
- [ ] CI зелёный на тестовом PR (ссылка в описании PR).
- [ ] В репозитории нет ключей, сертификатов и Team ID в открытом виде, кроме заглушки в `Appfile`.
- [ ] `docs/release.md` позволяет выпустить билд человеку, который проект не видел.

## Не делать

- Публикацию в App Store.
- Скриншоты через `snapshot`.

## Проверка

```bash
bundle exec fastlane test
```
