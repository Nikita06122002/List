# T10: История и карточка упражнения

- **Волна:** 2
- **Зависит от:** T01, T04
- **Блокирует:** T11, T12
- **SPEC:** разделы 1 (метрика), 7 (экран 5, правила рабочего веса и лучшего подхода)

## Цель

Место, куда заходят вне зала посмотреть прогресс. И единственное место, где видна главная метрика продукта.

## Файлы

- `Packages/UI/Sources/HistoryFeature/**`, кроме файлов экспорта CSV (это T12)
- `Packages/UI/Tests/HistoryFeatureTests/**`

## Что сделать

1. `HistoryStats`: чистые функции без UI, покрытые тестами.
   - рабочий вес тренировки для упражнения
   - лучший подход упражнения
   - серия точек для графика: дата тренировки → рабочий вес
   - среднее `inputActions` на подход за последние 30 дней, `nil` без данных
2. `HistoryView(repositories:)`: строка метрики «В среднем 1,4 действия на подход за 30 дней», ниже список тренировок по `finishedWorkouts(limit: 100)`: дата, название дня, число упражнений и подходов.
3. Детали тренировки: упражнения и подходы в формате `100 × 8`.
4. `ExerciseDetailView`: плитки «Рабочий вес» с изменением за 8 недель и «Лучший подход» с датой, график Swift Charts (`BarMark`, последняя точка акцентом), последние 10 тренировок с подходами одной строкой `100 × 8, 8, 8, 7`. Переход в карточку из деталей тренировки.
5. Пустые состояния: нет тренировок, у упражнения одна тренировка (график скрыт, текст «График появится после второй тренировки»).
6. Тулбар: место под кнопку экспорта, саму кнопку и логику делает T12. Оставь `ToolbarItem` с `EmptyView` и комментарием `// T12`.
7. Превью на in-memory хранилище с историей за 8 недель (генератор истории в превью-хелпере модуля).

## Критерии приёмки

- [ ] Тесты `HistoryStats`: рабочий вес = максимум; лучший подход при равном весе берёт больше повторов; серия отсортирована по дате; метрика считает только последние 30 дней и игнорирует тренировки без подходов.
- [ ] Превью: список, детали тренировки, карточка с графиком, оба пустых состояния.
- [ ] График читается VoiceOver: `accessibilityLabel` с итогом «Рабочий вес вырос с 90 до 100 кг».
- [ ] Нет ни одного hex, числа отступа или строки без String Catalog.

## Не делать

- Удаление и редактирование тренировок в истории.
- Экспорт.
