# T03: WorkoutEngine

- **Волна:** 1
- **Зависит от:** T00
- **Блокирует:** T06
- **SPEC:** разделы 4 (важные решения), 5, 6.2

## Цель

Вся логика тренировки в одном актёре, полностью покрытая тестами. Это сердце продукта: от правил предложения подхода зависит, сколько действий тратит пользователь.

## Файлы

- `Packages/Core/Sources/WorkoutEngine/**`
- `Packages/Core/Tests/WorkoutEngineTests/**`

## Что сделать

1. Реализовать `WorkoutEngine` по сигнатурам и правилам 1-7 из SPEC 6.2.
2. В тестах свои фейки репозиториев в памяти (`actor FakeWorkoutRepository` и т. п.) в тестовом таргете. От T01 не зависеть.
3. `start(dayID:)` берёт день из `activeProgram()`, копирует план в `Workout.plan`, сохраняет, возвращает снапшот с предложением первого подхода.
4. `skipExercise()` переходит к следующему упражнению без записи подходов. На последнем упражнении завершает сессию (`isFinished = true`).
5. `finish()` проставляет `finishedAt = now()`, сохраняет, возвращает тренировку. После этого сессии нет. `discard()` удаляет активную тренировку через `WorkoutRepository.delete(workoutID:)`, в историю она не попадает.
6. Все вычисления веса в `Decimal`.

## Критерии приёмки

Тест на каждый пункт, время через фиксированный `now`.

- [ ] Правило 1, все четыре ветки: вес из текущей тренировки, из подхода N прошлого раза, из последнего подхода прошлого раза, 0 без истории.
- [ ] Правило 2, все три ветки для повторов.
- [ ] `previousWeight` и `previousReps` заполнены из прошлого раза для того же номера подхода и `nil`, если его не было.
- [ ] `adjust`: шаг по `weightStep` (2.5, 2, 5), нижние границы 0 кг и 1 повтор, `weightStep == 0` не меняет вес, `97.5 + 2.5 == 100` ровно.
- [ ] `logSet`: подход записан с `inputActions`, отдых `resting(endsAt: now + restSeconds)`, переход к следующему упражнению после последнего целевого подхода, `isFinished` после последнего подхода тренировки без отдыха.
- [ ] Отдых: при `now >= endsAt` снапшот показывает `idle`; `skipRest` сразу даёт `idle`.
- [ ] Ошибки: `noActiveSession` для всех методов кроме `start` и `resume`; `sessionAlreadyActive`; `dayNotFound`.
- [ ] Восстановление: после каждой операции новый экземпляр движка на тех же фейках через `resume()` отдаёт равный снапшот.
- [ ] Полный сценарий: день из 2 упражнений по 2 подхода, с одним `adjust`, от `start` до `finish`.
- [ ] Модуль не импортирует ничего кроме `Foundation`, `Domain`, `Storage`.

## Не делать

- Никаких таймеров, `Task.sleep`, уведомлений и ActivityKit. Это `Session`.
- Не зависеть от реализации SwiftData, только от протоколов.
