# T00: Каркас проекта и контракты

- **Волна:** 0
- **Зависит от:** нет
- **Блокирует:** все задачи
- **SPEC:** разделы 4, 5, 6, 7 (шрифты)

## Цель

Пустой, но собирающийся проект, где все публичные контракты из SPEC раздел 6 уже объявлены. После этой задачи пять исполнителей волны 1 могут работать параллельно, не дожидаясь друг друга.

## Файлы

- `project.yml`, `.gitignore`
- `README.md`: только новый раздел «Сборка» в конце, остальное не трогать
- `Lift/` (таргет приложения), `LiftWidgets/` (Widget Extension)
- `Packages/Core/Package.swift` и все `Sources/*`, `Tests/*`
- `Packages/UI/Package.swift` и все `Sources/*`, `Tests/*`
- `Packages/*/Sources/*/AGENTS.md`
- `Lift/Resources/Fonts/`, `Lift/Resources/Localizable.xcstrings`

## Что сделать

1. `project.yml` для XcodeGen: таргеты `Lift` и `LiftWidgets`, схема `Lift`, iOS 17.0, Swift 6, strict concurrency complete, App Group `group.ru.nikita.lift` в entitlements обоих таргетов, `NSSupportsLiveActivities = YES`, `UIAppFonts`. `.xcodeproj` в `.gitignore`.
2. Пакет `Core` с таргетами `Domain`, `Storage`, `WorkoutEngine` и тестовыми таргетами к каждому. Платформы iOS 17, macOS 14.
3. Пакет `UI` с таргетами `DesignSystem`, `LiveActivityShared`, `Session`, `Intents`, `TodayFeature`, `WorkoutFeature`, `ProgramFeature`, `HistoryFeature` и тестовыми таргетами к `DesignSystem`, `Session`, `Intents`, `ProgramFeature`, `HistoryFeature`. Платформа iOS 17. Зависимости между таргетами строго по таблице SPEC раздел 4.
4. `Domain` реализовать полностью: все типы из SPEC раздел 5 с публичными инициализаторами.
5. Остальные контракты из раздела 6 объявить с точными сигнатурами. Тела-заглушки: методы бросают `StubError.notImplemented` (свой internal enum в каждом модуле) или возвращают пустые значения. `fatalError` не использовать: заглушка не должна ронять превью.
6. Приложение запускается и показывает `TabView` с тремя пустыми вкладками: «Сегодня», «Программа», «История». Расширение собирается и регистрирует `WorkoutActivityWidget` (пустая вьюха).
7. Положить шрифты Unbounded (500, 700) и Onest (400, 500, 600, 700) в `Lift/Resources/Fonts`. Если скачать нельзя, оставить папку с `README.md`, где перечислены нужные файлы, и не ломать сборку.
8. В каждом модуле `AGENTS.md` на 10-20 строк: за что отвечает модуль, от чего зависит, чего в нём делать нельзя, как его тестировать.
9. В каждом тестовом таргете один тест-заглушка `@Test func moduleLinks()`, чтобы `swift test` и `xcodebuild test` проходили. Тест-экшен схемы `Lift` включает все тестовые таргеты обоих пакетов, чтобы работал `-only-testing:<Target>`.

## Критерии приёмки

- [ ] `xcodegen generate` без ошибок, `xcodebuild build` для схемы `Lift` без предупреждений.
- [ ] `swift test --package-path Packages/Core` зелёный на macOS.
- [ ] `xcodebuild test` зелёный на симуляторе.
- [ ] Все сигнатуры из SPEC раздел 6 есть в коде и совпадают дословно. Таблица соответствия «сигнатура в SPEC → файл» в описании PR.
- [ ] Граф зависимостей таргетов совпадает с таблицей SPEC раздел 4. `Core` не импортирует UIKit, SwiftUI, ActivityKit, WidgetKit.
- [ ] Приложение запускается на симуляторе с тремя вкладками.
- [ ] У каждого модуля есть `AGENTS.md`.

## Не делать

- Никакой реальной логики хранения, движка и экранов.
- Никаких сторонних зависимостей, включая Tuist и SwiftLint.

## Проверка

```bash
xcodegen generate
swift test --package-path Packages/Core
xcodebuild -scheme Lift -destination 'platform=iOS Simulator,name=<SIM>' test
```

После мержа гейт G0: владелец утверждает контракты.
