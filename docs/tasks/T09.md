# T09: Экран программы

- **Волна:** 2
- **Зависит от:** T01, T02, T04
- **Блокирует:** T11
- **SPEC:** разделы 5 (`Program`, `ProgramDay`, `PlannedExercise`), 7 (экран 4)

## Цель

Пользователь собирает свою программу за пару минут один раз и потом сюда почти не заходит.

## Файлы

- `Packages/UI/Sources/ProgramFeature/**`
- `Packages/UI/Tests/ProgramFeatureTests/**`

## Что сделать

1. `ProgramView(repositories: Repositories)`. Модель экрана `@Observable` внутри модуля, работает через `ProgramRepository` и `ExerciseRepository`.
2. Нет активной программы: пустое состояние с двумя кнопками «Создать программу» и «Взять пример» (`DemoProgram.make(from:)` из `Storage`).
3. Список дней, перестановка, удаление свайпом, добавление. Поля дня: название, день недели (или «без дня»).
4. Экран дня: упражнения по порядку, у каждого «4 × 8, отдых 2:00». Перестановка и удаление.
5. Добавление упражнения: поиск по справочнику с фильтром по типу оборудования, создание своего (название, оборудование, шаг подставляется по типу).
6. Редактор упражнения в дне: подходы 1-10, повторы 1-50, отдых 30-600 с шагом 15. Значения по умолчанию 3 × 10, отдых 2:00.
7. Сохранение сразу при каждом изменении, без кнопки «Сохранить».
8. Превью: пустое состояние, программа из трёх дней, экран дня, поиск.

## Критерии приёмки

- [ ] Программу из трёх дней по 5 упражнений можно собрать без клавиатуры, кроме названий дней и поиска.
- [ ] Изменения переживают перезапуск приложения (проверка вручную на симуляторе, видео или скриншоты в PR).
- [ ] Правка программы во время активной тренировки не меняет идущую тренировку (план копируется при старте, SPEC 5). Ручная проверка.
- [ ] Ограничения диапазонов из п. 6 соблюдаются, тест на модель экрана.
- [ ] Нет ни одного hex, числа отступа или строки без String Catalog.

## Не делать

- Несколько программ, шаблоны, импорт.
- Поле группы мышц.
