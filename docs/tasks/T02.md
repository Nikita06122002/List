# T02: Справочник упражнений

- **Волна:** 1
- **Зависит от:** T00
- **Блокирует:** T09
- **SPEC:** разделы 5 (`Exercise`), 6.1 (`ExerciseSeed`)

## Цель

Встроенный справочник из 60-80 упражнений, которые реально делают в обычном зале.

## Файлы

- `Packages/Core/Sources/Storage/Resources/exercises.json`
- `Packages/Core/Sources/Storage/ExerciseSeed.swift`
- `Packages/Core/Tests/StorageTests/ExerciseSeedTests.swift`
- `Packages/Core/Package.swift`: только строка `resources: [.process("Resources")]` у таргета `Storage`, если её нет

## Что сделать

1. JSON-массив объектов `{ "id": "<UUID>", "name": "Жим лёжа", "equipment": "barbell", "weightStep": 2.5, "muscleGroup": "chest" }`. Поле `muscleGroup` в `Exercise` не попадает (декодер его игнорирует), оно нужно для теста и на будущее. Значения: `chest`, `back`, `legs`, `shoulders`, `biceps`, `triceps`, `core`. UUID постоянные, сгенерировать один раз и больше не менять: на них будет ссылаться история пользователей.
2. Охват: грудь, спина, ноги, плечи, бицепс, трицепс, пресс. Штанга, гантели, тренажёры, блоки, свой вес. Минимум по 6 упражнений на группу.
3. Названия как говорят в российском зале: «Жим лёжа», «Тяга верхнего блока», «Румынская тяга», «Разгибания на блоке», «Французский жим».
4. Шаг веса по типу: штанга 2.5, гантели 2, тренажёр 5, блок 5, свой вес 0.
5. `ExerciseSeed.exercises()` читает JSON из `Bundle.module`, `isCustom = false`.

## Критерии приёмки

- [ ] В JSON от 60 до 80 упражнений.
- [ ] Тест: все `id` уникальны и валидны, все `name` уникальны без учёта регистра.
- [ ] Тест: каждое значение `equipment` есть в `Equipment`, `weightStep` соответствует типу по правилу из п. 4.
- [ ] Тест: в каждой из 7 групп по `muscleGroup` минимум 6 упражнений.
- [ ] Есть упражнения из макетов: жим лёжа, жим гантелей на наклонной, разводка в кроссовере, французский жим, разгибания на блоке.

- Не трогать остальной код `Storage`.
