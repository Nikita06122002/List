# T12: Экспорт в CSV

- **Волна:** 3
- **Зависит от:** T10
- **Блокирует:** T14
- **SPEC:** раздел 8

## Цель

Пользователь может забрать свои данные в любой момент. Это и страховка, и аргумент «данные твои».

## Файлы

- `Packages/UI/Sources/HistoryFeature/Export/**`
- `Packages/UI/Sources/HistoryFeature/HistoryView.swift`: только замена заглушки `// T12` в тулбаре
- `Packages/UI/Tests/HistoryFeatureTests/CSVExporterTests.swift`

## Что сделать

1. `CSVExporter`: чистая функция `[Workout] + [Exercise] → Data` по формату SPEC 8. Дата `yyyy-MM-dd` в часовом поясе устройства, BOM, `;`, десятичная запятая.
2. Экранирование: поле с `;`, кавычкой или переводом строки в двойных кавычках, кавычки удваиваются.
3. Кнопка `ShareLink` в тулбаре истории, файл `lift-export-<дата>.csv` через `Transferable` с `FileRepresentation`.
4. Упражнение, которого нет в справочнике (удалённое своё), выгружается как «Неизвестное упражнение».

## Критерии приёмки

- [ ] Тест: заголовок и строки совпадают с примером из SPEC 8 байт в байт, включая BOM.
- [ ] Тест: `97.5` → `97,5`, название с `;` и кавычками экранировано.
- [ ] Тест: порядок строк по дате тренировки, затем по порядку упражнений, затем по `order` подхода.
- [ ] Ручная проверка: файл открывается в Numbers без мастера импорта, колонки на месте (скриншот в PR).

- Импорт.
- Другие форматы.
