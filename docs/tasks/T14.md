# T14: Интеграция и полировка по заметкам из зала

- **Волна:** 4
- **Зависит от:** T11, T12, гейт G1
- **Блокирует:** гейт G2
- **SPEC:** весь

## Цель

Довести MVP до состояния, когда его не стыдно отдать 5-10 знакомым. Новых фич нет, только исправления и то, что всплыло в зале.

## Как устроена задача

T14 не делает один агент. Оркестратор читает `docs/gym-notes/*.md`, режет заметки на подзадачи `T14.1`, `T14.2` и т. д. по шаблону остальных задач и запускает их обычным циклом. Этот файл задаёт рамку и финальный чек-лист.

## Что точно проверить

1. Метрика: по данным с реальной тренировки среднее действий на подход. Если больше 2, найти сценарий, который съедает действия, и завести подзадачу.
2. Live Activity на длинной тренировке, 1,5-2 часа: не пропадает, таймер верный, кнопки отвечают.
3. Кнопка Action и Siri в зале с потными руками и в перчатках.
4. Восстановление после убийства приложения посреди отдыха.
5. Поведение без интернета и в режиме энергосбережения.
6. Крупный шрифт Dynamic Type и VoiceOver на трёх главных экранах.
7. Русские тексты: опечатки, падежи («1 подход», «2 подхода», «5 подходов» через плюрализацию String Catalog).

## Финальный чек-лист перед G2

- [ ] Все подзадачи T14.x смержены с APPROVE ревьюера.
- [ ] Две тренировки подряд в зале без ручных правок данных.
- [ ] Среднее действий на подход по этим тренировкам не больше 2.
- [ ] Нет падений в журнале устройства за эти тренировки.
- [ ] `bundle exec fastlane test` зелёный.
- [ ] Владелец прошёл сценарии из SPEC 3 сам.

После чек-листа владелец запускает `bundle exec fastlane beta` и приглашает тестировщиков.
