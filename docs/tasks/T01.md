# T01: Storage на SwiftData

- **Волна:** 1
- **Зависит от:** T00
- **Блокирует:** T06, T09, T10
- **SPEC:** разделы 4 (важные решения, п. 1), 5, 6.1

## Цель

Рабочее хранилище: SwiftData-схема, три репозитория, фабрики `live` и `inMemory`.

## Файлы

- `Packages/Core/Sources/Storage/**`, кроме `Resources/exercises.json` и `ExerciseSeed.swift` (это T02)
- `Packages/Core/Tests/StorageTests/**`

## Что сделать

1. `@Model`-классы для упражнения, программы, дня, тренировки, подхода. `PlannedExercise` можно хранить как `Codable`-массив внутри дня и тренировки, это проще связей.
2. Маппинг `@Model` ↔ доменные структуры. `@Model` наружу не выходят, они `internal`.
3. Реализации трёх репозиториев на `@ModelActor`.
4. `StorageFactory.live(appGroup:)`: контейнер в `FileManager.containerURL(forSecurityApplicationGroupIdentifier:)`. Для тестов рядом `internal static func live(storeURL: URL)`, публичный метод вызывает её. При пустой таблице упражнений засев через `ExerciseSeed.exercises()`. Пока T02 не смержен, `ExerciseSeed` возвращает заглушку из T00, это нормально.
5. `StorageFactory.inMemory(seed:)`: контейнер `isStoredInMemoryOnly`. При `seed: true` засев упражнений и программа из `DemoProgram.make(from:)`. `DemoProgram` реализовать здесь: «Пн грудь, Ср спина, Пт ноги», 4-5 упражнений в дне, упражнения ищутся по названию, отсутствующие пропускаются.
6. `lastSets(exerciseID:)`: подходы упражнения из последней по `startedAt` завершённой тренировки, где оно есть, отсортированные по `order`.

## Критерии приёмки

- [ ] Тест: сохранить и прочитать каждую доменную сущность, все поля совпадают, включая `Decimal` 97.5 и порядок дней и упражнений.
- [ ] Тест: `activeWorkout()` возвращает только тренировку с `finishedAt == nil`.
- [ ] Тест: `lastSets` берёт последнюю завершённую тренировку, игнорирует активную, сортирует по `order`, возвращает пусто без истории.
- [ ] Тест: `finishedWorkouts` и `workouts(containing:)` отдают новые первыми и уважают `limit`.
- [ ] Тест: `delete(workoutID:)` удаляет тренировку вместе с подходами.
- [ ] Тест: повторный вызов засева не создаёт дублей.
- [ ] Тест: данные переживают пересоздание контейнера на одном файле (временная директория вместо App Group).
- [ ] Модуль не импортирует UIKit и SwiftUI.
