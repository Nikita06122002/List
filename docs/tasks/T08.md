# T08: Экран тренировки

- **Волна:** 2
- **Зависит от:** T04, T06
- **Блокирует:** T11
- **SPEC:** разделы 3, 7 (экран 2)

## Цель

Экран, которым пользуются, когда телефон всё-таки в руке. Всё то же, что в Live Activity, плюс список сделанных подходов и управление тренировкой.

## Файлы

- `Packages/UI/Sources/WorkoutFeature/**`

## Что сделать

1. `WorkoutView(coordinator: SessionCoordinator)`. Данные только из `coordinator.snapshot`, действия только через `coordinator.perform(_:source: .app)`.
2. Раскладка по SPEC 7, экран 2 и макету `docs/design/workout.dc.html`: шапка, заголовок упражнения, карточка с двумя `ValueTile`, «Готово» или `RestBanner`, сделанные подходы, плашка «Дальше».
3. Время с начала тренировки в шапке через `Text(startedAt, style: .timer)`.
4. «Завершить»: подтверждение через `confirmationDialog` с вариантами «Сохранить тренировку» (`finish`) и «Удалить без сохранения» (`discard`), если не сделано ни одного подхода, сразу `discard` без вопроса.
5. Пропуск упражнения через меню в шапке (`skipExercise`).
6. Тактильный отклик `.sensoryFeedback(.success, trigger:)` на записанный подход.
7. `lastError` показывается ненавязчиво (баннер сверху на 3 секунды), не алертом.
8. Превью: середина упражнения, отдых, последний подход, тренировка закончена. Через `StorageFactory.inMemory(seed: true)` и мок-презентеры из T06.

## Критерии приёмки

- [ ] Сценарий из SPEC 3 «подход на повтор меньше» делается за 2 касания на экране.
- [ ] Все 4 превью собираются, скриншоты в PR рядом с макетом.
- [ ] Нет ни одного hex, числа отступа или строки без String Catalog.
- [ ] VoiceOver: плитки читаются как «Вес, 100 килограммов», кнопки шага подписаны.
- [ ] Экран не ломается на iPhone SE (375×667) и с крупным шрифтом Dynamic Type `xxxLarge`: контент скроллится.

## Не делать

- Никакой логики веса и повторов во вьюхе.
- Не вызывать движок напрямую.
