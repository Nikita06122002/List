# T04: DesignSystem

- **Волна:** 1
- **Зависит от:** T00
- **Блокирует:** T07, T08, T09, T10
- **SPEC:** раздел 7

## Цель

Токены и компоненты, из которых собираются все экраны и Live Activity. После этой задачи в фичах не должно быть ни одного hex-цвета, числа отступа или имени шрифта.

## Файлы

- `Packages/UI/Sources/DesignSystem/**`
- `Packages/UI/Tests/DesignSystemTests/**`

## Что сделать

1. `Palette` с токенами из таблицы SPEC 7 как `Color`.
2. `Spacing`, `Radius` как `CGFloat`-константы из SPEC 7.
3. `FontStyle`: `largeTitle` (Unbounded 700, 28-30), `number` (Unbounded 700, 40, monospacedDigit), `numberSmall` (Unbounded 700, 26), `title` (Onest 700, 22), `body` (Onest 400, 15), `bodyStrong` (Onest 600, 15), `caption` (Onest 400, 13). Фолбэк на системный rounded, если шрифт не зарегистрирован. Поддержка Dynamic Type через `relativeTo:`.
4. `WeightFormatter`: `Decimal` → строка по правилу SPEC 7 (`100`, `97,5`), плюс вариант с единицей `100 кг`. Формат подхода `100 × 8`.
5. Компоненты:
   - `PrimaryButton` (акцентная, высота 64 или 52 через параметр)
   - `StepButton` (`−2,5`, `+1`, высота 48, фон `control`)
   - `ValueTile` (подпись, большое число, два `StepButton` снизу)
   - `Card` (контейнер `surface`, радиус 24, отступ 20)
   - `ListRow` (слева текст, справа приглушённый текст, разделитель)
   - `RestBanner` (подпись «Отдых», таймер через `Text(timerInterval:)`, кнопка «Пропустить»)
6. Превью для каждого компонента, на тёмном фоне.
7. Все строки компонентов приходят параметрами, своих текстов в `DesignSystem` нет, кроме подписи «Отдых» и «Пропустить» в `RestBanner` через String Catalog модуля.

## Критерии приёмки

- [ ] Тест `WeightFormatter`: `100` → «100», `97.5` → «97,5», `2` → «2», `0` → «0», `102.25` → «102,25», формат подхода «100 × 8».
- [ ] У каждого компонента есть `#Preview`.
- [ ] Все кнопки не ниже 44 pt по высоте, иконочные с `accessibilityLabel` параметром.
- [ ] Контраст `textSecondary` на `background` и `surface` не ниже 4.5:1, `onAccent` на `accent` не ниже 4.5:1. Значения посчитаны в тесте.
- [ ] Модуль не зависит ни от одного другого модуля проекта.

## Не делать

- Никакой бизнес-логики и доменных типов, кроме `Decimal` в форматтере.
- Не делать светлую тему.
