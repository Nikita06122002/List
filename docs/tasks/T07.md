# T07: Live Activity

- **Волна:** 2
- **Зависит от:** T04, T05
- **Блокирует:** T11
- **SPEC:** разделы 3, 6.3, 7 (экран 3)

## Цель

Live Activity, с которой проходит большая часть тренировки. Ради этого экрана делается продукт: подход записывается отсюда за одно касание.

## Файлы

- `Packages/UI/Sources/LiveActivityShared/**`
- `LiftWidgets/**`

## Что сделать

1. `WorkoutActivityAttributes` по SPEC 6.3 (тип уже есть из T00, проверить, что не менялся).
2. Вьюха локскрина по SPEC 7, экран 3: строка «Жим лёжа · подход 3 из 4», «100 кг × 8» крупно, справа отдых через `Text(timerInterval:countsDown:)`, если `restEndsAt` в будущем. Ряд из 4 кнопок шага, под ним «Готово» на всю ширину.
3. Кнопки через `Button(intent:)`: `AdjustSetIntent(kind: …)`, `LogSetIntent()`. Во время отдыха вместо «Готово» кнопка «Пропустить отдых» с `SkipRestIntent()`. Отдых считается закончившимся, если `context.isStale == true`: `Session` ставит `staleDate = restEndsAt`, и система перерисует активность без пуша. Подпись шага веса из `weightStep` (`−2,5`, `+5`). При `weightStep == 0` кнопок веса нет, повторы растягиваются на ряд.
4. `isFinished`: «Тренировка завершена», без кнопок.
5. Dynamic Island: compact leading иконка штанги, compact trailing таймер отдыха или `3/4`; minimal таймер или иконка; expanded как локскрин без ряда шага, только «Готово».
6. Цвета и шрифты только из `DesignSystem`. Фон Live Activity `background` через `activityBackgroundTint`.
7. Превью для всех состояний через `#Preview(as: .content, using: attributes) { WorkoutActivityWidget() } contentStates: { … }`: подход, отдых, свой вес без шага веса, длинное название упражнения в две строки, завершено.
8. `LiftWidgets`: `@main WidgetBundle` с одним `WorkoutActivityWidget`.

## Критерии приёмки

- [ ] Превью всех 5 состояний собираются и выглядят по макету (скриншоты в PR).
- [ ] Длинное название не ломает раскладку: обрезается на двух строках.
- [ ] Все кнопки вызывают интенты, никакой логики во вьюхе.
- [ ] Кнопки не ниже 44 pt, у кнопок шага `accessibilityLabel` вроде «Прибавить 2,5 килограмма».
- [ ] Расширение собирается и не тянет `WorkoutEngine`, `Storage`, `Session`.

## Не делать

- Не обновлять Live Activity из расширения. Обновляет только `Session` в приложении.
- Не использовать пуш-обновления.
