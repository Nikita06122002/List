# T11: Экран «Сегодня» и сборка приложения

- **Волна:** 3
- **Зависит от:** T06, T07, T08, T09, T10
- **Блокирует:** T14
- **SPEC:** разделы 3, 4 (таргеты, важные решения), 7 (экран 1)

## Цель

Собрать всё в одно приложение: граф зависимостей, вкладки, экран «Сегодня», переходы, восстановление тренировки после перезапуска.

## Файлы

- `Packages/UI/Sources/TodayFeature/**`
- `Lift/**`

## Что сделать

1. `AppDependencies` в `Lift`: `StorageFactory.live(appGroup:)`, `WorkoutEngine`, `LiveActivityPresenter`, `LocalRestNotifier`, `SessionCoordinator`. Создаётся один раз в `App.init`.
2. В `App.init`, синхронно, до первого кадра: `SessionCommandRegistry.handler = coordinator`. Без этого интент из Live Activity, поднявший приложение из фона, не найдёт обработчик.
3. При запуске и при возврате в foreground `coordinator.restore()`.
4. `TabView`: «Сегодня», «Программа», «История». Иконки SF Symbols. `.preferredColorScheme(.dark)`.
5. `TodayView` по SPEC 7, экран 1 и макету `docs/design/today.dc.html`:
   - день программы на сегодня по `weekday`, иначе ближайший следующий с кнопкой «Начать всё равно»
   - у каждого упражнения «подходы × вес из прошлого раза» (через `lastSets`; нет истории: только подходы × повторы)
   - кнопка «Начать тренировку» → `coordinator.start(dayID:)` → экран тренировки на весь экран (`fullScreenCover`)
   - активная тренировка: «Продолжить» вместо «Начать»
   - неделя: 7 кружков, сегодняшний обведён, дни с завершёнными тренировками закрашены
   - нет программы: пустое состояние с переходом во вкладку «Программа»
6. Ошибка открытия хранилища: экран с текстом ошибки и кнопкой «Попробовать снова», без падения.
7. Иконка приложения: заглушка в цветах `accent` на `background` с силуэтом штанги.

## Критерии приёмки

- [ ] Ручной сценарий на симуляторе, видео в PR: создать программу из примера, начать тренировку, записать 3 подхода из приложения, свернуть, записать подход кнопкой в Live Activity, вернуться в приложение и увидеть этот подход.
- [ ] Ручной сценарий: убить приложение во время тренировки, нажать «Готово» в Live Activity, открыть приложение: подход записан, тренировка продолжается.
- [ ] Ручной сценарий: интент «Подход сделан» из приложения Команды записывает подход при свёрнутом приложении.
- [ ] Превью `TodayView`: обычный день, активная тренировка, нет программы, сегодня нет дня.
- [ ] Нет ни одного hex, числа отступа или строки без String Catalog.
