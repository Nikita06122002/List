# Макеты

Четыре экрана MVP в формате HTML с inline-стилями. Читай как текст: цвета, размеры, отступы и тексты в разметке точные.

| Файл | Экран | SPEC 7 |
| --- | --- | --- |
| `today.dc.html` | Сегодня | экран 1 |
| `workout.dc.html` | Тренировка, с рабочими кнопками шага и таймером в `<script>` | экран 2 |
| `live-activity.dc.html` | Live Activity на локскрине и Dynamic Island | экран 3 |
| `history.dc.html` | Карточка упражнения с графиком | экран 5 |

Экрана программы (экран 4) в макетах нет, делай по описанию в SPEC и токенам.

Пиксели из макета переводятся в токены `DesignSystem`, ближайшее значение. Шрифты Onest и Unbounded. Цифры и даты в макетах примерные.

`support.js`, на который ссылаются файлы, в репозитории нет. Он нужен только для просмотра в редакторе макетов.
